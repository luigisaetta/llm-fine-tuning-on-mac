# Qwen3-0.6B Model Acquisition Specification

## Problem

The project needs one concrete, small open-weight base model that learners can download reliably before running local LoRA experiments.

## Scope

The selected model is [`Qwen/Qwen3-0.6B`](https://huggingface.co/Qwen/Qwen3-0.6B), acquired from the Hugging Face Hub using the `hf` command-line interface. The README documents a reproducible full download command.

## Model decision

| Field | Value |
| --- | --- |
| Hugging Face repository | `Qwen/Qwen3-0.6B` |
| Model type | Causal language model |
| Parameter count | 0.6B (0.44B non-embedding, according to the model card) |
| Artifact format | Safetensors |
| Licence | Apache-2.0 |
| Pinned revision | `c1899de289a04d12100db370d81485cdf75e47ca` |
| Revision checked | 2026-09-01 |

The pinned revision is the Hugging Face Hub commit returned by the model API on the checked date. Future upgrades require a specification update that records the new full commit hash and the reason for changing it.

## Acquisition contract

* `huggingface_hub` is a direct requirement so the `hf` CLI is available in the project environment.
* The documented full download must use the repository identifier and pinned revision above.
* The standard destination is `artifacts/models/Qwen3-0.6B`; it is ignored by Git.
* The model is public at the checked revision, so authentication is not required for the standard download. Authentication remains optional for a user whose Hub setup requires it.
* No Hugging Face token may appear in source, notebooks, documentation examples, shell history, or committed configuration.

## Out of scope

Downloading quantized variants, converting the model to other formats, downloading the base-only repository, or running model inference are out of scope for this acquisition step. These require later specifications.

## Acceptance criteria

* `requirements.txt` explicitly includes `huggingface_hub`.
* The README identifies `Qwen/Qwen3-0.6B`, its pinned revision, destination, and full download command.
* The destination and its Hugging Face metadata cache are excluded from Git.
* The command succeeds from the `llm-fine-tuning-on-mac` environment when network access is available, then prints the local destination path.

## Verification

* Run `hf --help` from the named Conda environment.
* Run `hf download --help` and confirm support for the documented `--revision` and `--local-dir` options.
* Optionally run the full command, then verify that `config.json`, tokenizer files, and `model.safetensors` exist under the selected destination.
* Run `git check-ignore artifacts/models/Qwen3-0.6B/model.safetensors` to confirm that model artifacts cannot be committed accidentally.
